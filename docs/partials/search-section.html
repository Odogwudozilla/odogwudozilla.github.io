BFS uses a queue. With equally weighted moves, its first route to the goal is a shortest route. DFS uses a stack and can find a longer route.

Moves have equal cost: up, right, down or left. Walls cannot be crossed. This deterministic example runs entirely in your browser.

Read the search trace and comparison

BFS takes the oldest pending cell; DFS takes the newest. Neighbours are considered up, right, down, left. The choice changes both the route and how much of the board is explored. Neither algorithm is always faster on every board.
