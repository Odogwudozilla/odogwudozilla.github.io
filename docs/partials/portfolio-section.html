02 / Community software

Private repository

Fusion Almere FC

I’m building a club platform that brings registration, player profiles, and administration together, replacing fragmented spreadsheet workflows with a shared application.

  • Public registration & player portal
  • Role-based administration & member management
  • Java API backed by Supabase Auth and PostgreSQL
  • Java 21
  • Spring Boot
  • Angular
  • Supabase
Explore the club platform +

The challenge

Help players register and manage their profiles while giving club administrators a consistent way to manage members and teams.

My part

I’m building an Angular front end and a Spring Boot REST API with Supabase authentication, database, and storage. Features include registration, profile editing, searchable member records, and team-management services.

An engineering detail

Registration checks for duplicate accounts and records an audit trail. Notification emails are sent after the database transaction commits, avoiding messages for rolled-back changes.

Where it stands

An evolving MVP with a public test deployment on Vercel and Render. Further membership features and payment-import workflows are under active development.

03 / Data & reliability

Private repository

HomeWizard Energy Intelligence

A Java collector and an authenticated React application that turn smart-meter readings into historical insights, making energy use, data quality, and load-shifting options easier to explore.

  • Durable collection with retry and replay
  • Historical imports, coverage, and freshness indicators
  • Measured data kept distinct from modelled scenarios
  • Java
  • React
  • SQLite
  • Supabase
Explore the energy application +

The challenge

Make energy history useful while keeping missing readings and estimates visible. The collector also needs to recover reliably from interruptions.

My part

The project spans HomeWizard API integration, a Java collector, durable local SQLite storage, authenticated Supabase ingestion, and an interface built with React and TypeScript.

An engineering detail

Readings are persisted before upload, then replayed with ingestion that prevents duplicate records. The interface shows coverage and freshness so users can assess the data.

Where it stands

A private hosted application with historical exploration and load-shifting features. Tariff, solar, and battery scenarios continue to evolve, with cost comparisons still in progress.
