Policy-management APIs

I help replace SOAP interfaces with REST APIs. This includes checking existing behaviour, defining request and response models, and documenting endpoints in OpenAPI. Authentication, authorisation, HTTP errors, and API versioning are part of that work.

Compatibility and frontend changes

I compare API behaviour with its contract and documentation, investigate mismatches, and plan changes for existing consumers. I also help retire older frontend paths while preserving the routes, permissions, and workflows still in use.

Defect investigation and testing

I reproduce reported problems, trace their causes through code, data, and APIs, and add tests for the affected behaviour. My work includes integration and regression tests, browser tests with Playwright, and release checks.

Technical analysis and delivery

I turn business requests into requirements and acceptance criteria, refine stories with colleagues, review changes, and write technical notes and release documentation. I also explore AI-assisted tools for triage and technical analysis.

Registration and administration

I’m developing the Angular front end and Spring Boot REST API. Players can register and edit their profiles; administrators can search member records and manage teams.

Registration checks and email

Registration checks for duplicate accounts and records an audit trail. Notification emails are sent after the database transaction commits, so a rolled-back registration does not trigger an email.

Development status

The MVP has a public test deployment on Vercel and Render. Membership features and payment-import workflows are still under development.

HomeWizard Energy Intelligence

I’m building an application to collect smart-meter readings, review energy history, and compare load-shifting scenarios.

More about the energy application +

Personal project

Private repository
  • Local storage, upload retries, and replay
  • Historical imports and data-coverage checks
  • Recorded readings kept separate from estimates
  • Java
  • React
  • SQLite
  • Supabase

Collection and recovery

The Java collector reads the HomeWizard API and saves readings in SQLite before uploading them. Failed uploads can be replayed, and ingestion prevents duplicate records.

Energy history

The authenticated React and TypeScript interface uses Supabase data. It shows reading history, coverage, and freshness so missing data is visible when reviewing energy use.

Development status

The private hosted application supports historical exploration and load-shifting scenarios. Tariff, solar, battery, and cost comparisons are still being developed.
